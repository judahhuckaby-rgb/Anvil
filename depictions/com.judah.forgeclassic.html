Forge Classic

GitHub, on devices GitHub forgot

A native GitHub browser for iOS 6 and later, for when the website itself won't load on an old device. Universal binary: armv7 and arm64.

What it does

  • Search repositories, or open owner/repo directly
  • Read the README and browse code and folders
  • Browse releases and download .deb and .ipa files to the device
  • Find tweaks by name across jailbreak repos
  • Save favorites and check them for new releases
  • Copy downloads to /var/mobile/Documents for dpkg or iFile

Notes

  • Add a GitHub token in Settings to lift the hourly request limit from 60 to 5,000.
  • Requires iOS 6.0 or later.
